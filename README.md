# LukClips

**Cole o link da live. Saia com cortes prontos.**

O LukClips acha os melhores momentos de uma live (calor do chat, mapa de calor do YouTube, gritos e risadas, movimento da tela) e gera cortes verticais com legenda, título e hashtags para TikTok, Reels e Shorts.

🔗 **Site e planos:** https://lukclips.pages.dev
⬇️ **Baixar:** [última versão](https://github.com/LUKbrDEV/LukClips/releases/latest) (precisa de um serial de licença)
